# The Mulem Programming Language
This is a new programming language (work in progress).

I'm sure most programmers have thought about making their own programming language before. This language is a collection of different ideas that I've hand while learning other programming languages and thinking "if I were to make changes to this language, I would do this or that." This is a side-project that I am working on for fun, so don't expect too much from it. I mainly use it as a way to warm up before working on other things. 

Mulem is currently in the planning phase (version 0.1). There is no working compiler or interpreter yet. See [reference.md](https://github.com/lemlac/mulem/blob/main/docs/reference.md) for the current schematics of the language. This might change regularly until I feel that it's ready.
